# Working on the ulo website

These guides describe `services/www/`. The public ulo documentation is
written in `../../docs/guides/`, rendered by `src/pages/docs/`, and published at
`ulo.sh/docs`.

| Task                                             | Guide                             |
| ------------------------------------------------ | --------------------------------- |
| Find a page, component, or data module           | [Architecture](architecture.md)   |
| Run the site and check a change                  | [Development](development.md)     |
| Change contact details or legacy email redirects | [Contact](contact.md)             |
| Record or change the terminal demo               | [Terminal demo](terminal-demo.md) |
| Review, merge, or release a change               | [Deployment](deployment.md)       |

Read the guide for the task, then the implementation it names. Keep each guide
about its current contract. Git history records superseded work.
